# 论文速读：CombLM-Adapting-Black-Box-Language-Models-through-Small-Fine

## 一句话总结
本文提出一种轻量级方法，仅需访问大语言模型的输出概率分布（无需权重或中间激活），通过微调一个小尺寸白盒领域专家模型，并学习一个概率级组合函数，将两者结合以实现黑盒大模型的领域/任务适配。在三个领域适配任务和一个机器翻译下游任务上，该方法均优于单独使用大黑盒模型或小专家模型，最高提升达 9%（困惑度）。

## 研究问题与动机
- **核心问题**：现有语言模型（LM）领域适配技术通常假设拥有模型的白盒访问权限（可修改参数），但当前最高质量的模型（如 GPT-4、PaLM-2）仅作为黑盒通过推理 API 提供，且即使权重可用，微调大型 LM 的计算成本对大多数研究者来说也过高。
- **现有方法不足**：全量微调、参数高效适配技术（如 adapters、LoRA、soft-prompt tuning）都需要白盒访问和完整反向传播，与黑盒模型不兼容；离散提示调优（discrete prompt tuning）仅适用于检索零样本/少样本提示的有限场景，无法作为通用黑盒模型适配方法；同时期工作（如 KNN-adapter）仅在小规模 GPT-2 模型上实验，且依赖数据仓库的构建，限制了应用范围。
- **研究空白**：缺乏一种能够充分利用强大黑盒 LM 能力、同时适应新领域或下游任务的轻量级适配方法。

## 核心贡献（创新点）
1. **提出首个仅基于概率输出的黑盒 LM 适配框架**：通过微调一个小尺寸白盒领域专家 LM，并在概率层学习组合函数将其与大黑盒 LM 结合，无需访问黑盒模型的权重或中间激活。
2. **设计并系统评估了多种容量递增的概率组合函数**：从简单的均值、常数标量/向量，到基于熵的标量/向量组合，再到基于完整概率分布的标量/向量组合，研究了组合函数容量与数据需求的关系。
3. **验证了方法在领域适配和下游任务上的有效性**：在三个不同领域（Amazon Reviews、Enron Emails、FreeLaw）和机器翻译任务上，结合模型均优于单一模型，领域适配最高提升 9% 困惑度，机器翻译提升 6% BLEURT。
4. **揭示了组合方法在保留通用语言建模能力方面的差异**：发现不同组合方法在领域适配后对通用性能（The Pile 上的困惑度）的退化程度不同，且通过将目标领域与通用文本混合拟合组合函数可有效缓解这种退化。

## 方法详解
方法分为两个主要步骤：

**步骤 1：训练小型领域专家 LM**
- 在目标领域特定的小数据集上微调预训练的小尺寸白盒 LM（OPT-1.3B），得到 $P_S$（小模型分布）。
- 使用 Adam 优化器，学习率 4e-4，序列长度 1024，批次大小 92160 tokens。

**步骤 2：学习概率级组合函数**
- 定义组合函数 $f: \mathbb{R}^{|V|} \times \mathbb{R}^{|V|} \to \mathbb{R}^|V|$，输入两个模型的完整概率分布 $P_S(\cdot|\mathbf{x})$ 和 $P_L(\cdot|\mathbf{x})$，输出组合分布 $P_C$。
- 考虑的七种组合函数（按容量递增）：
  1. **Mean**：算术平均，$f(y_1, y_2) = (y_1 + y_2)/2$，无学习参数。
  2. **Constant-scalar**：线性组合，$f(y_1, y_2) = \lambda y_1 + (1-\lambda)y_2$，单个可学习标量 $\lambda$。
  3. **Constant-vector**：token 级线性组合，$\lambda \in \mathbb{R}^{|V|}$，逐元素加权。
  4. **Entropy-scalar**：根据两个分布的熵 $H(y_1), H(y_2)$ 通过小神经网络预测标量 $\lambda$，再进行线性组合。
  5. **Entropy-vector**：基于熵预测 token 级向量 $\lambda \in \mathbb{R}^{|V|}$。
  6. **Full-scalar**：基于完整输入分布预测标量 $\lambda$。
  7. **Full-vector**：基于完整输入分布预测 token 级向量 $\lambda$。
- 组合网络架构：输入层根据方法不同为 2 维（熵）、$2|V|$ 维（完整分布）或无输入，后接 1D BatchNorm、两个 512 维隐藏层（ReLU），输出层经 sigmoid 激活限制在 (0,1)。
- 优化：Adam 优化器，学习率 2e-3（constant-vector 为 1e-2），批次大小 1024，仅训练 1 个 epoch。
- **关键约束**：仅需前向传播获取概率分布，无需权重或激活值访问；所有模型需共享 tokenizer。

## 实验与结果
**领域适配实验**：
- **数据集**：Amazon Reviews（20.37 → 15.50 困惑度，相对提升 9%）、Enron Emails（5.53 → 3.24，提升 2%）、FreeLaw（6.50 → 4.78，提升 4%）。
- **基线**：OPT-1.3B 微调（领域专家）、OPT-30B（黑盒大模型）、均值组合、七种学习组合函数、Max-prob oracle（理论上限）。
- **最强结果**：Entropy-scalar 在三个领域均表现最佳或次佳，在 Amazon Reviews 上达到 15.50 困惑度，显著优于 OPT-30B 的 20.37 和 OPT-1.3B FT 的 17.00。
- **数据效率**：即使仅用 100 个序列拟合，entropy-scalar 仍能达到 15.51 困惑度，而 full-scalar/vector 需要更多数据（1000 序列）才能发挥优势。

**机器翻译实验**：
- **任务**：English-Czech 和 English-German 翻译（WMT21），使用 BLEURT 评估。
- **最强结果**：Entropy-vector 在 en-de 上达到 58.11 BLEURT，en-cs 上 35.41，de-en 上 69.44，cs-en 上 64.06，平均 56.76，优于 OPT-30B 的 53.56 和 OPT-1.3B FT 的 53.36。
- **关键发现**：简单均值组合已能达到第二好成绩，组合函数对 MT 影响相对较小，但所有学习方法均带来显著改进。

**通用性能保持**：
- 在 The Pile 上评估通用语言建模能力，发现 entropy-scalar 在 Amazon 适配后 The Pile 困惑度为 7.35，远优于小模型 FT 的 19.78，且通过混合通用数据拟合可进一步缓解退化（The Pile 困惑度降至 6.94）。

## 相关工作脉络
1. **传统领域适配**（Gururangan et al., 2020; Devlin et al., 2019）：需要白盒访问和全量微调，计算成本高，无法用于黑盒模型。
2. **参数高效适配**（LoRA、adapters、prompt tuning）：减少参数量但仍需白盒访问和反向传播，与黑盒 API 不兼容。
3. **黑盒提示调优**（Shin et al., 2020; Sun et al., 2022）：仅适用于检索零/少样本提示的任务增强，非通用适配方法。
4. **KNN-adapter**（Huang et al., 2023，同期工作）：利用数据仓库检索增强黑盒 LM，但仅限小模型实验，且依赖数据仓库构建，应用场景受限。
5. **领域专家组合**（Li et al., 2022; Gururangan et al., 2023）：在预训练阶段训练独立专家并在参数级组合，无法利用现有黑盒模型；本文方法专注于适配已有强大黑盒模型。
6. **模块化语言模型**（Gururangan et al., 2022; Pfeiffer et al., 2022）：通过替换 Transformer 组件实现领域/语言特异性，属于预训练方法，不适用于黑盒适配场景。

## 局限性与未来方向
- **概率访问限制**：方法假设可获取完整输出概率分布，但某些 API（如 OpenAI）仅提供 top-5 概率，虽然 constant/entropy 方法可适应，但 full 方法受限。
- **计算成本**：虽无需微调黑盒模型，但仍需对拟合集进行黑盒前向传播，API 调用可能产生较高成本。
- **性能差距**：当前方法与 max-prob oracle（理论最优组合）仍有显著差距，表明组合函数仍有优化空间。
- **未来方向**：探索更优的组合函数设计以缩小与 oracle 的差距；研究如何在有限概率访问（如仅 top-K）下提升性能；扩展至更多下游任务和领域。

## 研究启发与可借鉴点
1. **概率级组合范式**：仅依赖模型输出概率而非内部状态即可实现有效适配，为黑盒模型利用提供了新思路，可迁移至其他需要适配黑盒模型的场景。
2. **熵作为组合信号**：将输出分布熵作为组合函数的输入特征，能平衡领域专家与通用模型，这一设计简洁有效，值得在其他多模型融合任务中尝试。
3. **数据效率与容量权衡**：低容量组合方法（如 entropy-scalar）在极少数据（100 序列）下仍表现良好，而高容量方法需更多数据，这一发现为实际部署中的资源权衡提供了指导。
4. **通用性能退化缓解**：通过混合通用数据拟合组合函数，可在领域适配的同时保持通用能力，这一策略对防止灾难性遗忘具有借鉴价值。
5. **tokenizer 共享约束**：方法要求所有模型共享 tokenizer，这一约束在实际应用中需注意，可启发未来研究探索跨 tokenizer 的适配方法。

## 关键术语表
- **黑盒语言模型**：仅通过 API 提供输入输出概率，不公开模型权重或内部激活的模型。
- **领域专家模型**：在特定领域数据上微调的小规模语言模型，擅长处理该领域的语言模式。
- **概率级组合**：在模型输出概率分布层面进行加权融合，而非在参数或激活层面组合。
- **熵标量组合**：根据两个模型输出分布的熵值预测组合权重，熵反映模型的不确定性。
- **Max-prob oracle**：理想组合上限，为每个 token 100% 分配权重给预测更好的模型。
- **BLEURT**：基于 BERT 的神经机器翻译评估指标，比 BLEU 更能捕捉语义相似度。
- **参数高效适配**：通过微调少量参数（如 adapters、LoRA）实现模型适配，减少计算成本。
- **The Pile**：包含 800GB 多样化文本的大型语言建模数据集，常用于评估通用语言能力。
