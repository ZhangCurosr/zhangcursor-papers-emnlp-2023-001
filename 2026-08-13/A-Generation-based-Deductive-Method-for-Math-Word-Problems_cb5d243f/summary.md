# 论文速读：A Generation-based Deductive Method for Math Word Problems

## 一句话总结
论文提出 GeDe（Generation-based Deductive）模型，通过多元有向无环图（mDAG）和重编码器策略，在数学应用题求解中兼顾生成式方法的表达力与演绎式方法的中间量复用能力，有效支持线性方程求解等高级多变量算子。

## 研究问题与动机
1. 现有生成方法（seq2seq/seq2tree）在求解含高级算子（如线性方程求解）的数学应用题时，会重复生成相同的子表达式，导致效率低下且难以复用中间结果。
2. 演绎方法（如基于二元有向无环图 bDAG）虽然能自然复用中间量，但仅支持二元基本算子，无法处理接收多个输入并返回多个输出的多变量高级算子。
3. 需要一种统一框架，既能通过中间量复用避免重复计算，又能直接表达和生成多变量操作序列。
4. 现有演绎方法依赖“枚举‑分类”的贪心策略，候选操作空间巨大，计算开销昂贵。

## 核心贡献（创新点）
1. **提出 mDAG（多元有向无环图）表示**：将操作节点扩展为包含基本或高级算子及多个输入数量，直接支持多变量运算，区别于传统 bDAG 仅支持二元算子。
2. **设计 GeDe 生成‑演绎模型**：在生成模型中引入重编码器，使模型具备演绎式的中间量复用能力，同时避免演绎方法高昂的枚举开销。
3. **重编码器与动态数量嵌入**：每步将原始问题与已生成中间量联合编码，动态更新各数量的语义表示，区别于静态嵌入或仅编码原始问题的方案。
4. **层次束搜索算法**：分别进行令牌级（内层）和操作级（外层）搜索，兼顾单操作生成质量与全局操作序列最优，以往演绎方法仅能实现贪心搜索。
5. **构建 CMWPA 合成数据集**：自动合成含线性方程求解、二次函数极值/积分等高级算子的数学应用题，验证 mDAG 表示与 GeDe 的有效性。

## 方法详解
1. **mDAG 表示与目标**：问题 \(P\) 包含 \(n\) 个词和 \(m\) 个数量 token，目标逻辑形式为操作序列 \(O = (o^1, o^2, \dots, o^{|O|})\)，其中每个操作 \(o^t\) 是拓扑排序后的多变量操作 token 序列。
2. **重编码器**：将原始问题中的数量替换为通用 token \([QTT_i]\)，得到 \(P_r\)；第 \(t\) 步输入 \(P_{in}^t = P_r \oplus\) 已生成操作及新数量。使用 PLM（如 RoBERTa）编码得到推理状态 \(\mathbf{R}^t\)，并按位置提取各数量表示 \(\mathbf{Q}^t\)。
3. **解码器**：采用 GRU + 多头注意力。操作生成以 \([BOS]\) 开始，\([EOS]\) 结束当前操作，\([EOO]\) 结束整个序列。第 \(i\) 个 token 的隐状态 \(\mathbf{h}_i^t = \mathrm{GRU}(\mathbf{h}_{i-1}^t, \mathbf{a}_i^t)\)，经注意力得到增强状态 \(\mathbf{A}_i^t = \mathrm{MHA}(\mathbf{h}_i^t, \mathbf{R}^t)\)，输出概率 \(p(a_i^t | \cdot) = \mathrm{softmax}(\mathbf{A}_i^t [\mathbf{V} \mid \mathbf{Q}^t]^T)\)。
4. **训练目标**：最大化操作序列条件概率 \(p(O|P) = \prod_{t=1}^{|O|} \prod_{i=1}^{|o^t|+1} p(a_i^t | o^{<t}, a_{<i}^t, P)\)，交叉熵损失。
5. **层次束搜索**：内层束搜索生成候选操作，得分 \(ibs^t = \frac{1}{l}\sum_{i=1}^l \log p(a_i^t)\)；将内层得分经 softmax 近似为操作概率 \(p(o^t) = \mathrm{softmax}(\exp(ibs^t))\)；外层束搜索聚合操作级得分 \(obs = \frac{1}{T}\sum_{t=1}^T \log p(o^t)\)，每步保留 top‑K。
6. **解码约束**：解码过程中增量过滤非法 token（如要求算子时拒绝数量），解码后剔除不合逻辑的操作（如 \([QTT_i] - [QTT_i]\)）。

## 实验与结果
1. **数据集**：MAWPS、Math23k、MathQA、SVAMP（公开）及自建 CMWPA（含线性方程求解、二次函数极值/积分高级算子）。
2. **基线**：S2S（GroupAttn、RoBERTaGen、Generate&Rank）、S2T/G2T（Graph2Tree、HMS）、DR（RoBERTa‑DR）。
3. **CMWPA 结果**：GeDe + mDAG 准确率达 **95.0%**，推理时间 400 ms/sample；GeDe + BET（二叉表达式树）仅 32.0%，证明高级算子显著降低学习难度（平均操作数 2.98 vs 35.03）。
4. **现有数据集**：GeDe 在 MathQA 达 **81.5%**（比最强基线 RoBERTa‑DR 高 **+2.9%**），Math23k 测试集 85.4%，MAWPS 92.3%，SVAMP 45.7%。GeDe 参数 126M，优于 610M 参数的 Generate&Rank。
5. **细粒度分析**：在 ≥5 操作的 MathQA 样本上，GeDe 77.5% vs RoBERTa‑DR 71.4%，体现对复杂推理步骤的鲁棒性。
6. **消融**：移除重编码器降 5.7%，移除动态数量嵌入降 1.2%，移除层次束搜索降 0.5%，验证各组件有效性。

## 相关工作脉络
1. **生成式方法**（Wang et al., 2017; Xie & Sun, 2019）直接生成表达式序列或二叉树，未解决子表达式重复生成问题。
2. **演绎方法**（Cao et al., 2021; Jie et al., 2022）基于 bDAG 枚举候选二元操作并贪心选择，仅支持二元算子且枚举开销大。
3. **生成‑排序方法**（Shen et al., 2021）先生成后排序表达式，未引入中间量复用机制。
4. **知识注入模型**（Wu et al., 2020; Liang et al., 2022）增强编码器表达能力，但底层表达形式仍受限于序列或二叉结构。
5. **本文定位**：统一生成式与演绎式，通过 mDAG 支持多变量高级算子，用重编码器实现中间量复用，用层次束搜索替代枚举，在表达力与效率间取得平衡。

## 局限性与未来方向
1. **长序列效率问题**：重编码器需拼接已生成操作，当操作序列较长时可能超出 PLM 输入长度限制，且时间复杂度随操作数增加而上升。
2. **高级算子泛化**：当前高级算子（线性方程、二次函数极值/积分）依赖人工模板生成，扩展至其他算子类型需重新定义模板。
3. **简单问题上优势有限**：在平均操作数较少的 MAWPS 上仅提升 0.3%，表明模型价值主要体现在多步复杂推理场景。
4. **未来方向**：研究生成过程中的输入序列压缩方法，支持更长推理链；探索更通用的高级算子表示与合成策略。

## 研究启发与可借鉴点
1. **重编码器设计**：迭代联合编码原始输入与动态生成的中间表示，可有效传递跨步上下文信息，适用于其他需要逐步推理并复用中间结果的生成任务。
2. **层次束搜索**：将搜索空间拆分为低层 token 级和高层结构级，分别优化后再聚合，可推广至嵌套序列生成（如代码生成、逻辑公式生成）。
3. **mDAG 表示思想**：将二叉结构扩展为多变量有向无环图，能更紧凑地表达含高级算子的数学流程，为领域特定的逻辑形式设计提供参考。
4. **合成数据集构建**：通过人工模板自动生成带标注的多变量操作序列，可在数据稀缺的新领域快速构建高质量训练数据。
5. **参数效率对比**：小参数模型（126M）通过合理的结构设计可达到与大参数模型（610M）相当甚至更优的性能，启示在资源受限场景下优先优化架构而非盲目扩大模型。

## 关键术语表
**mDAG**：多元有向无环图，节点表示包含多变量输入的操作，替代传统二叉表达式树，支持高级算子。  
**GeDe**：Generation‑based Deductive 模型，结合生成式解码与演绎式中间量复用的统一框架。  
**重编码器**：每步将原始问题与已生成中间量联合编码的模块，动态更新推理状态和数量嵌入。  
**层次束搜索**：内层令牌级束搜索生成候选操作，外层操作级束搜索选择全局最优操作序列。  
**高级算子**：接收多个数量并返回多个数量的预定义算子，如线性方程求解器、二次函数极值/积分求解器。  
**动态数量嵌入**：每个数量 token 的表示随推理步骤动态更新，反映其在当前上下文中的语义。  
**CMWPA**：Complex Math Word Problems with Advanced operators，含高级算子的合成数学应用题数据集。  

## 可复现要素
- **数据集**：MAWPS、Math23k、MathQA、SVAMP 为公开数据集；CMWPA 为自建合成数据集，代码中提供模板。
- **代码**：已开源，地址 https://github.com/hyx1999/GeDe。
- **权重**：论文未明确公开预训练权重，需自行训练。
- **关键超参**：重编码器使用 RoBERTa‑base（126M 参数），优化器 AdamW，学习率 2e‑5，weight decay 1e‑2，batch size 8，beam size K=4，训练设备 RTX 3090 24G GPU。
- **实现细节**：重编码器为双向 PLM，解码器为 GRU + 多头注意力，解码约束基于 PICARD 思想。
