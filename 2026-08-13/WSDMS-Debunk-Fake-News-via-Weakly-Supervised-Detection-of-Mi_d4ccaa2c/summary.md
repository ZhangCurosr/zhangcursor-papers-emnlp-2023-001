# 论文速读：WSDMS-Debunk-Fake-News-via-Weakly-Supervised-Detection-of-Mi

## 一句话总结
本文提出 WSDMS 模型，基于多重实例学习（MIL）框架，仅利用文章级标签（弱监督）即可同时完成句子级虚假信息检测和文章级假新闻检测，并通过显式的句子-社交对话树链接机制与加权集体注意力提升检测精度，在三个真实数据集上均超越现有最强基线。

## 研究问题与动机
1. **细粒度检测缺失**：现有假新闻检测方法主要聚焦粗粒度的文章级分类，无法定位文章中具体哪些句子包含虚假信息，而虚假新闻常将真实与虚假信息混合以提升可信度。
2. **句子级标注成本高昂**：获取句子级真实性标签需要标注员逐一进行事实核查，成本极高，难以规模化。
3. **社交对话与句子的对应难题**：谣言检测模型依赖特定声明对应的社交对话，但建立社交对话与文章中具体句子的精确对应关系十分困难。
4. **弱监督学习的潜力未被充分挖掘**：文章级标签公开易得，如何利用这些弱标签驱动句子级检测是一个有待探索的问题。

## 核心贡献（创新点）
1. **提出句子级虚假信息检测新任务**：在统一模型中同时学习句子级虚假信息与文章级真假检测，区别于现有仅做文章级分类的工作。
2. **设计 MIL 弱监督模型 WSDMS**：仅依赖文章级标签训练，即可推断句子级虚假信息与文章级真实性，避免了昂贵的句子级标注。
3. **构建显式的句子-对话树链接机制**：基于阈值相似度连接句子与社交对话树，并利用 KernelGAT 建模帖子间交互，比全连接方案更高效且效果相当。
4. **引入加权集体注意力机制**：针对标准 MIL"只要有一个正实例即判定为正"的过强假设，通过注意力权重聚合句子级预测，容忍句子级预测误差。
5. **设计一致性损失函数**：利用文章级标签实现弱监督，同时约束相似句子的预测应保持一致，缓解预测偏差。

## 方法详解
1. **输入嵌入**：使用 SBERT 将新闻标题、句子和社交帖子映射为固定维度向量。
2. **帖子交互嵌入**：对每个对话树，构建帖子间余弦相似度矩阵，通过 K 个高斯核函数（K=10）计算核特征，再用 softmax 注意力聚合邻居帖子表示，得到增强后的帖子表示。
3. **句子-对话树链接**：对每对 (句子, 对话树) 计算余弦相似度，若超过全局阈值 τ（取分数范围的中位数）则建立链接，避免全连接的计算开销。
4. **句子级虚假信息检测**：对与句子 s_i 相连的对话树集合 τ_i，通过注意力机制聚合树表示，与社会上下文无关的原始表示拼接后，经全连接层输出句子级虚假概率 p̂_i。
5. **文章级真实性推断**：用 Transformer 对标题和所有句子上下文表示进行编码，再通过以标题为 query 的注意力机制计算各句子的注意力权重 α_i，最终通过加权求和得到文章级虚假概率 ŷ。
6. **损失函数**：L(A) = λ·C(A) + (1-λ)·||y_A - ŷ_A||²₂，其中一致性项 C(A) = ΣᵢΣⱼ exp(-||ŝ_i - ŝ_j||²₂ · ||p̂_i - p̂_j||²₂)，λ=0.5，确保相似句子的预测一致，同时监督文章级预测。

## 实验与结果
- **数据集**：PolitiFact（政治类，共1270篇）、GossipCop（娱乐类，共22153篇）、BuzzNews（开放域，自建共481篇），均在测试集上进行句子级人工标注（标注者一致性0.793）。
- **文章级检测基线**：DeClarE、HAN、dEFEND、BerTweet、GCAN、Bi-GCN、KAN、SureFact（最强基线）。WSDMS 在 PolitiFact/GossipCop/BuzzNews 上 F1 分别为 **0.943/0.870/0.853**，分别超越 SureFact **约2个百分点**。WSDMS 训练时间从4.5小时降至2小时。
- **句子级检测基线**：在相同句子级监督下，WSDMS（需大量句子标签的基线公平对比）F1 为 **0.527/0.519/0.524**；而当使用原始文章级标签训练的 WSDMS(o) 时，F1 达到 **0.655/0.646/0.598**，**超越所有需要句子级标注的监督基线**（如 KAN 的 0.584/0.550/0.550）。
- **消融实验**：移除对话树、核函数、加权集体注意力、一致性损失均导致性能下降；标题作为普通句子处理也会损害性能。
- **用户研究**：提供句子级虚假标记和证据后，用户判定准确率从0.784提升至0.958，耗时减少70%，置信度显著提升。

## 相关工作脉络
1. **假新闻检测**：从早期手工特征（语言、视觉、时序）转向深度学习（DNN、GNN），代表工作包括 dEFEND、GCAN、Bi-GCN、KAN、SureFact，但均聚焦文章级分类。
2. **谣言检测**：聚焦声明级验证而非文章级，代表工作包括 tree-structured RNN 方法和 KernelGAT，但依赖声明与社交对话的精确对应。
3. **多重实例学习（MIL）**：从阈值假设发展为加权集体假设，应用于推荐、情感分析等领域，本文将其首次系统引入假新闻的句子级检测。
4. **弱监督细粒度检测**：本文是 MIL 在假新闻句子级检测中的首次应用，与现有监督式句子级方法形成互补。
5. **社交上下文利用**：从图神经网络建模传播结构到跨模态融合，本文强调显式句子-对话树链接而非全连接或主题级聚类。
6. **一致性正则化**：本文设计的一致性损失与自监督学习中的对比学习思想相通，但专为此任务的弱监督设定定制。

## 局限性与未来方向
1. **未考虑消息传播方向**：对话树的表示未区分自上而下和自下而上的传播路径。
2. **无法处理逻辑不一致组合**：多个真实句子组合可能构成逻辑谬误或矛盾，当前模型未建模句子间关系。
3. **平台偏差**：仅使用 Twitter 社交上下文数据，可能存在平台偏见，可引入 Facebook 等多平台数据。
4. **缺少语篇特征**：未利用句间语篇关系（discourse relations）等更细粒度的文本特征。

## 研究启发与可借鉴点
1. **MIL 弱监督范式可迁移**：对于需要细粒度标注但仅能获得粗粒度标签的任务（如段落级异常检测、文档级错误定位），可借鉴本文的 MIL 框架。
2. **显式链接替代全连接**：基于阈值的句子-证据链接机制在保持性能的同时大幅降低计算成本，适用于其他长文本-证据匹配任务。
3. **一致性损失设计精巧**：利用 L2 核函数约束相似实例预测一致性的思路，可推广至其他弱监督细粒度学习场景。
4. **用户研究验证可解释性价值**：提供细粒度定位和证据可显著提升用户判断质量和效率，这对面向实际应用的系统具有重要参考价值。
5. **弱监督充分利用公开数据**：仅用文章级标签即可达到甚至超越监督基线，说明大规模弱标签数据值得被充分挖掘。

## 关键术语表
**WSDMS**：Weakly Supervised Detection of Misinforming Sentences，本文提出的基于 MIL 的弱监督句子级虚假信息检测模型。
**多重实例学习（MIL）**：一种弱监督学习框架，仅给定包级标签，推断包内实例级标签。
**KernelGAT**：基于高斯核函数的图注意力网络，用于建模帖子间交互并生成增强的帖子表示。
**加权集体 MIL 假设**：不同于传统阈值 MIL，通过为实例分配不同权重来综合推断包级标签，避免少数极端实例主导预测。
**一致性损失**：约束相似句子具有相似预测结果的损失项，利用文章级标签实现弱监督下的句子级表征学习。
**阈值链接机制**：基于句子与对话树间余弦相似度超过全局阈值来建立链接，避免全连接的计算开销。
